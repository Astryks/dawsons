Split a song into tracks

Drop in a song you have the rights to. The quick split runs in this tab and sorts it into drums, bass, melody, and the rest — each on its own track. A real vocal / drums / bass / other split needs the free local Demucs engine (no paid API).

To run Demucs: from services/ai-sidecar, install requirements and start uvicorn app.main:app --host 127.0.0.1 --port 8765. Paste that URL above. The first split downloads the free htdemucs weights. This static site cannot host that model itself.
